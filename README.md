# Digit Recognition

Recognise handwritten digits and test how image cleaning and augmentation affect results.

## Approach

- Exploration with PCA, LDA and clustering
- Classical machine learning models
- Neural networks and image augmentation

## Start here

[1.Notebook.ipynb](1.Notebook.ipynb)

## Notebooks

- 1.Notebook.ipynb: exploration
- 2.MLModels.ipynb: classical models
- 3.NeuralNets.ipynb: neural networks
- 4.ImageAgumentation.ipynb: augmentation

## Data

MNIST. A trained model is saved as `model.h5`.

The `earlier-version/` folder keeps files from earlier versions of this project (Digit-Recognition) that differ from the files above.
